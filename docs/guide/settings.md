# Settings

This guide is split by topic so support answers can link directly to a specific setting.

## Open Settings

- **macOS**: `Settings...` from app menu (or toolbar gear where available)
- **iOS**: toolbar/settings sheet
- **visionOS**: settings popover from top ornament toolbar

## Notes

- Settings are persisted via user defaults.
- Some options are platform-specific and are hidden on unsupported platforms.
- AirPods head-tracking tuning keys exist internally, but detailed controls are currently not exposed in the Settings UI.
