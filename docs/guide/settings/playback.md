# Playback

## Playback FPS

**Platform**: macOS, iOS, visionOS

Options: `1`, `5`, `10`, `30`, `60`, `120` fps

Default: `1 fps`

Effect: controls frame animation tick interval.

## Loop Playback

**Platform**: macOS, iOS, visionOS

Default: On

Effect:
- On: wrap to frame `0` at end
- Off: stop playback at final frame
