# Inspector Formatting

## Float Display

**Platform**: macOS, iOS, visionOS

Options:
- `Fixed`
- `Significant`
- `Scientific`

Default: `Fixed`

Effect:
- `Fixed`: fixed decimal places
- `Significant`: significant-digit formatting
- `Scientific`: scientific notation

## Float Precision

**Platform**: macOS, iOS, visionOS

Range: `3` to `8`

Default: `4`

Effect: controls displayed precision in inspector numeric readouts and node option editors.
