# 0.1.5

**Released:** 2026-02-17

## Highlights
- Initial submission to App Store (macOS, visionOS, iOS)
- Added FPS (idle, max) settings
- Switched renderer workflow
- UI overhaul
- Improved gesture control while in Spatial

## Rendering
- Switched to deferred rendering (G-buffer) and tightened up the render pipeline.
- Added/iterated on weighted OIT and improved transparency handling paths.
- Improved spatial rendering drawables / SpatialRenderer and pass structure (including in-pass work).
- Updated lighting/shading: DeferredLighting changes, plus Phong/Toon style options and shader refactors.
- Moved to reverse‑Z depth handling and fixed projection/clipping issues (esp. orthographic).
- Improved picking pipeline: in-pass pick capture, format unification, and memory usage reductions.
- Unified render attachment formats + pipeline setup for more consistent frame outputs.
- Added/updated overlays & interactions: infinite mesh grid overlay, orbit-center ring interaction/toggle.
- Misc render tuning: FPS setting changes and small ALU/perf tweaks.
- Recover support for simulator.

## UI
- Major inspector UI overhaul: refactored inspector layouts, sidebar behavior, and toolbar.
- Added a more native inspector table experience and improved inspector/toolbar ergonomics.
- Broad UI tweaks across iOS / macOS / visionOS for consistency.
- Fixed interaction issues: 3D gesture fixes and added spatial vertical rotation mode.
