## Build 62 <Badge type="warning" text="Internal TestFlight" />

**Uploaded:** 2026-02-26

### Parsing
- DeepMD raw file loading should be faster now

### Visualization
- Raw arrow visualization now connects directly to vector property outputs
- Orbit ring rendering refactored for cleaner platform separation

### Robustness
- Added limits to prevent unbounded memory use when reading malformed or very large files
- GZip streaming now handles backpressure and cleans up correctly on termination
- Compressed file index cache uses bounded LRU eviction instead of growing unbounded
- Renderer resource allocation now fails gracefully instead of crashing

### Performance
- Orbit ring mesh buffers are cached and reused across frames instead of re-allocated each frame
- Recent document file-existence checks moved off the main thread
- Marching cubes neighbor tracking uses a more memory-efficient structure

### CI / Infra
- Distribution channel detection is cached at launch instead of re-checked on every view
