# 0.2.0 <Badge type="warning" text="TestFlight" />

## Build 73 <Badge type="warning" text="Internal TestFlight" />

**Uploaded:** 2026-07-20

First 0.2.0 build, for macOS, iOS, and visionOS. Quick Look thumbnails and the App Clip are not included in this build.

## Highlights
- Naiive is now a **document-based app** with its own `.naiive` file format
- Renderer moved to **Metal 4** on all device builds
- Node graph reworked into a **3-stage** Source / Compute / Present model
- **13 rendering styles**, including Comic, Goodsell, and Blueprint
- visionOS immersive experience redesigned around a compact control bar
- Big analysis speedup: bonds + RDF at ~900K atoms is ~20× faster with the new GPU path

## Documents & Files
- New `.naiive` document format: a document stores source-file references, the node graph, camera/view state, and per-source styling; source files can optionally be embedded as copies. A moved or missing source file no longer fails the open.
- Frame indices for `lammps/dump`, `.xyz`, and `.extxyz` are saved into the document, so reopening skips the trajectory scan.
- Import path rewrite (mmap + SIMD parsing): a 1M-atom LAMMPS dump imports in ~21 ms (was ~68 ms); warm gzip re-import ~14 ms (was ~257 ms).
- 14 supported format keys, including the generic NumPy `.npy` / `.npz` import added in 0.1.7.

## Node Graph
- 3-stage model: every node belongs to Source, Compute, or Present, and edges only flow forward. The sidebar and node editor are organized around the same three stages.
- New `table` wire type with plot nodes (XY Plot, Histogram Plot); analysis outputs are listed automatically as derived data.
- New Time Average node; RDF and MSD reworked for the new model. ~125 nodes across 21 categories.
- Optional GPU compute for RDF and Create Bonds (off by default, toggle in settings): at ~900K atoms, combined bonds + RDF drops from ~970 ms to ~43 ms (≈22×).
- Caching reworked: revisiting a frame while scrubbing is a cache hit, and cache memory is bounded by a byte budget instead of growing without limit.

## Rendering
- Metal 4 is now the sole command model on device builds (Metal 3 remains only for the simulator).
- Unified deferred main pass with memoryless attachments; weighted-OIT fixes (reverse-Z weighting, NaN pixels in dense transparent scenes).
- 13 rendering styles: Phong, Sketch, Toon, Retro Dither, Phong Metal, Phong Matte, Comic, Goodsell, Blueprint, Neon X-Ray, Chalkboard, Risograph, Stippling.
- Volume rendering: empty-space skipping, step-size opacity correction, and rays now stop at the first opaque surface — a volume cloud no longer shows through atoms in front of it.
- Imposter edge antialiasing via analytic coverage (instead of MSAA).

## visionOS
- While immersed, the viewer window swaps to a compact glass control bar; sidebar and inspector become ornaments toggled from the bar.
- Spatial pipelines are pre-warmed — no more multi-second hang when entering the immersive space.
- Fixed volume depth occlusion and volume flicker in spatial rendering.
- Gaze hover glow, world-fixed lighting, and stereo-stable style patterns (both eyes fuse instead of rivaling).

## UI
- App-wide design-system rework across macOS, iOS/iPadOS, and visionOS.
- Node editor rebuilt as a standalone package with three stage tabs (Source / Compute / Present) and cross-stage navigation.
- iOS shell redesigned around a full-bleed viewport with an adaptive navigation sheet.

## Viewers
- An iOS App Clip and macOS Quick Look preview/thumbnail extensions are implemented on the shared viewer engine; they roll out once the app is on the App Store.

## Internals
- Source tree reorganized into framework + app modules (NaiveCore, NaiveRenderKit, NaiveNodeEditor).
